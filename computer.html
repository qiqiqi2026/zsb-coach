专升本计算机：13 个模块，把零散知识串成一张网

计算机考的内容看起来杂：编程、网络、数据库、数据结构都考一点。 但真正的复习方法是「按模块建骨架，再往骨架里填考点」—— 13 个模块、76 个考点，每个考点配六阶段讲义、图解和配套题。

13 个模块，覆盖哪些内容

计算机基础编程基础Python 编程HTML 与 CSS JavaScript 前端网络安全爬虫与数据数据库 软件工程操作系统数据结构算法 网络基础

每个模块都从「这个东西解决什么问题」讲起，再进入语法、原理和典型题。 抽象内容配 SVG 图解，例如事件循环、三次握手、B+ 树、进程调度，先用图建立直觉，再落到文字定义。

非计算机专业，按这个顺序学

  • 先打底：计算机基础 + 编程基础，弄懂二进制、编码、变量、循环、函数。
  • 再写代码：Python 编程，语法少、反馈快，适合建立编程手感。
  • 然后看系统：操作系统 + 网络基础，理解进程、内存、IP、TCP 三次握手。
  • 接着管数据：数据库 + 爬虫与数据，会写 SQL、知道数据怎么存和取。
  • 最后攻难点：数据结构 + 算法 + 软件工程，掌握线性表、树、排序与复杂度分析。
  • 前端与安全：HTML/CSS、JavaScript、网络安全，按考纲要求补充即可。
Python：先会读，再会写

列表切片、字典、循环、函数是高频点；先把一段代码读懂，再自己写，比死记语法有效。

网络：抓住分层

把 OSI 与 TCP/IP 分层对应起来，每层记 2 到 3 个协议，三次握手和四次挥手要能画出来。

数据库：SQL 是得分点

SELECT、WHERE、GROUP BY、JOIN 必须能手写；范式与索引理解概念即可，不必背长定义。

数据结构：画图理解

链表指针、二叉树遍历、栈与队列，先画图再写步骤，比背代码更容易在考场还原。

易错提醒：「时间复杂度」和「空间复杂度」常被混着问； 冒泡、插入、归并、快速排序的最好/最坏情况要分开记，别只记一个平均值。

常见问题

完全没写过代码，能学吗？

能。编程基础模块从变量和循环讲起，Python 语法少、报错直观，适合零基础起步。

需要装编译器或软件吗？

不需要。讲义里的代码可以直接阅读和理解，配套题目以选择题和填空为主，浏览器打开就能学。

计算机题量够吗？

计算机共 308 道配套题，覆盖 76 个考点，每个考点不少于 3 道，按基础、变式、易错分层。
